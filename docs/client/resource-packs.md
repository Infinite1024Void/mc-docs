# Resource Packs

Resource packs change textures, sounds, language files, models, fonts, and other client-side assets.

## Install a resource pack

1. Download a resource pack that supports your Minecraft version.
2. Open Minecraft.
3. Go to **Options** > **Resource Packs**.
4. Open the resource pack folder.
5. Move the downloaded pack into the folder.
6. Enable the pack in-game.
