# Client Documentation

Client documentation focuses on the Minecraft installation that players run on their own computer.

Use this section when you want to:

- Install or update Minecraft.
- Add mods with loaders such as Fabric, Forge, or Quilt.
- Install shaders and resource packs.
- Troubleshoot crashes, missing dependencies, or version mismatches.
