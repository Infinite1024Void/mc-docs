# Client Setup

This page outlines the basic path for preparing a Minecraft client.

## 1. Choose an edition

- **Java Edition**: Best for modding, community servers, and custom launchers.
- **Bedrock Edition**: Best for cross-play with consoles, mobile devices, and Windows players.

## 2. Install the launcher

Install the official Minecraft Launcher or a trusted third-party launcher that supports the version and mod loader you plan to use.

## 3. Pick a game version

Match your client version to the server or modpack you want to play.

## 4. Launch once before modding

Launch the selected version at least once before installing mods so local game files are created.
