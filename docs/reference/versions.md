# Versions Reference

Version compatibility is one of the most important parts of Minecraft administration.

## Compatibility checklist

Before combining clients, servers, mods, plugins, or resource packs, confirm:

- Minecraft version.
- Java version.
- Mod loader and loader version.
- Plugin server software and build.
- Resource pack format support.
- Whether the server requires vanilla, modded, or proxy-compatible clients.

## Upgrade approach

1. Back up the server and client profiles.
2. Read release notes for server software, mods, and plugins.
3. Test upgrades in a separate folder or staging server.
4. Upgrade dependencies together when required.
5. Keep rollback files until the new version is stable.
