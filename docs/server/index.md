# Server Documentation

Server documentation focuses on hosting and maintaining Minecraft worlds for multiple players.

Use this section when you want to:

- Start a vanilla, Paper, Fabric, or Forge server.
- Configure player access and server settings.
- Install plugins or server-side mods.
- Improve performance and reliability.
