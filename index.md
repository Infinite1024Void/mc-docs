# Minecraft Docs

Welcome to the Minecraft documentation hub.

This site covers practical guides for running and customizing Minecraft on both sides of the game:

- **Client-side docs** for setup, mods, resource packs, and player troubleshooting.
- **Server-side docs** for hosting, configuration, plugins, performance, and administration.
- **Reference docs** for commonly used commands and version planning.

{: .tip }
> If you are playing Minecraft locally, start with the [client setup guide]({{ "/client/setup/" | relative_url }}). If you are hosting a world for other players, start with the [server setup guide]({{ "/server/setup/" | relative_url }}).
